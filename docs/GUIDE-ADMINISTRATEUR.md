# Guide de l'administrateur

Ce guide explique, en langage simple, comment gérer l'espace média de
Jean-Marc GNALI : audios, vidéos, livres et fichiers pratiques. Aucune
connaissance technique n'est nécessaire.

## 1. Se connecter

1. Rendez-vous sur `https://votre-site.com/admin/connexion`.
2. Entrez votre adresse e-mail et votre mot de passe.
3. Cliquez sur **Se connecter**.

Vous arrivez sur le **tableau de bord** : nombre de ressources publiées, de
brouillons, d'audios, de vidéos, de livres et de fichiers pratiques, ainsi que
des raccourcis « + Audio », « + Vidéo », « + Livre », « + Fichier pratique ».

## 2. Ajouter une ressource

1. Cliquez sur un raccourci du tableau de bord, ou sur **Ressources** puis
   **+ Nouvelle ressource**, et choisissez le type.
2. Remplissez le **titre** : l'adresse de la page (slug) se remplit seule.
3. **Description courte** (facultative) : une ou deux phrases affichées sur
   les cartes. **Description complète** : le texte de la fiche.
   Mise en forme possible : ligne vide = nouveau paragraphe, `## Titre` =
   sous-titre, `- élément` = liste, `**texte**` = gras.
4. Complétez la partie propre au type (voir ci-dessous), l'image, les
   catégories et les mots-clés.
5. Cliquez sur **Enregistrer comme brouillon** (invisible sur le site) ou
   choisissez le statut **Publié** puis **Créer la ressource**.

Les erreurs éventuelles s'affichent sous chaque champ ; vos saisies sont
conservées. Le message vert de confirmation n'apparaît qu'une fois
l'enregistrement réellement effectué.

### Audio

- **Fichier audio** : MP3, M4A, AAC, OGG ou WAV (200 Mo maximum). La durée
  est détectée automatiquement.
- **Lien Spotify** : dans Spotify, « Partager » > « Copier le lien », puis
  collez-le. Un fichier audio, un lien Spotify, ou les deux.
- **Série** (facultatif) : regroupe plusieurs épisodes ; un filtre « Série »
  apparaît alors sur la page Audios.

### Vidéo

Collez le lien **YouTube** ou **Vimeo** de la vidéo. Le fournisseur est
reconnu automatiquement et la miniature YouTube est utilisée si vous
n'ajoutez pas d'image. Vous pouvez aussi indiquer une version audio Spotify :
la ressource apparaîtra alors également dans la rubrique Audios.

### Livre

Ajoutez la couverture, l'auteur, le sous-titre et l'ISBN si vous les
connaissez, les formats disponibles, et uniquement les liens réels : lien de
lecture en ligne, lien d'achat, ou versions numériques téléchargeables.
Rien n'est affiché pour un champ laissé vide.

### Fichier pratique

Ajoutez un ou plusieurs fichiers : PDF, Word, Excel, PowerPoint,
OpenDocument, EPUB, TXT ou CSV (50 Mo maximum par fichier). Le format et la
taille sont affichés automatiquement aux visiteurs.

**Politique de téléchargement** : « Consultation et téléchargement » ou
« Consultation en ligne uniquement » (le bouton Télécharger est alors masqué).

## 3. Publier, programmer, mettre en avant

- **Statut** : Brouillon (invisible), Publié, Archivé (retiré du site sans
  être supprimé).
- **Date de publication** : vide = date du jour. Une date future programme
  l'apparition de la ressource sur le site.
- **Mettre en avant** : la ressource passe en tête des sélections de la page
  d'accueil.
- **Prévisualiser** (en haut de la page de modification) : affiche la fiche
  telle qu'elle apparaîtra, même en brouillon.

## 4. Gérer la liste des ressources

Le menu **Ressources** liste tout le contenu, filtrable par type et par
statut, avec une recherche instantanée. Sur chaque ligne : Modifier,
Aperçu / Voir, Publier / Dépublier, Archiver, Supprimer.

La suppression est définitive (fichiers compris) et demande une
confirmation. Pour retirer une ressource du site sans la perdre, préférez
**Archiver**.

## 5. Catégories

Menu **Catégories** : créer, renommer, décrire, illustrer (image
facultative), masquer (case « Catégorie active ») ou réordonner par
glisser-déposer. Seules les catégories actives contenant au moins une
ressource publiée apparaissent dans les filtres du site.

## 6. Paramètres (administrateurs uniquement)

- **Photo de Jean-Marc GNALI** : affichée sur l'accueil et la page À propos.
- **Page À propos** : accroche, introduction, biographie, démarche de
  transmission, citation. Chaque section vide est masquée.
- **Présentation et réseaux sociaux** : courte présentation et liens affichés
  dans le pied de page. Seuls les réseaux renseignés apparaissent.

## 7. Utilisateurs (administrateurs uniquement)

Le menu **Utilisateurs** permet de :
- créer un nouvel administrateur ou éditeur ;
- modifier le nom, le rôle ou le mot de passe d'un utilisateur ;
- désactiver un compte (recommandé plutôt que de le supprimer si la
  personne a déjà publié des ressources) ;
- supprimer un utilisateur (sauf votre propre compte).

## Besoin d'aide ?

Contactez la personne technique en charge de la maintenance du site pour
toute question qui n'est pas couverte par ce guide.
