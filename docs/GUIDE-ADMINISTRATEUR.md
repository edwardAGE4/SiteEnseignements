# Guide de l'administrateur

Ce guide explique, en langage simple, comment gerer le contenu de la
plateforme des enseignements du Pasteur Jean-Marc GNALI. Aucune connaissance
technique n'est necessaire.

## 1. Se connecter

1. Rendez-vous sur `https://votre-site.com/admin/connexion`.
2. Entrez votre adresse e-mail et votre mot de passe.
3. Cliquez sur **Se connecter**.

Vous arrivez alors sur le tableau de bord.

## 2. Ajouter un enseignement

1. Dans le menu de gauche, cliquez sur **Enseignements**.
2. Cliquez sur **+ Nouvel enseignement**.
3. Remplissez :
   - **Titre** : le titre de l'enseignement.
   - **Slug** : l'adresse web de la page, generee automatiquement a partir
     du titre (vous pouvez la modifier si besoin).
   - **Description** : un resume qui apparaitra sur la fiche et dans les
     moteurs de recherche.

### 3. Ajouter une video YouTube

Collez le lien complet de la video dans le champ **URL YouTube**
(exemple : `https://www.youtube.com/watch?v=XXXXXXXXXXX`).

### 4. Ajouter un audio Spotify

Collez le lien de l'episode dans le champ **URL Spotify**
(exemple : `https://open.spotify.com/episode/XXXXXXXXXXXXXXXXXXXXXX`).

### 5. Ajouter un document PDF

Cliquez sur le champ **Document PDF** et selectionnez le fichier sur votre
ordinateur (20 Mo maximum). L'envoi se fait automatiquement.

### 6. Ajouter une image

Cliquez sur le champ **Image de couverture** et selectionnez une photo
(formats acceptes : JPEG, PNG, WebP ; 8 Mo maximum).

### 7. Choisir une categorie

Cochez une ou plusieurs categories dans la liste proposee. Si la categorie
souhaitee n'existe pas encore, creez-la d'abord dans le menu **Categories**
(voir section 11).

### 8. Publier

En bas du formulaire, choisissez le statut :
- **Brouillon** : l'enseignement n'est pas visible par le public.
- **Publie** : l'enseignement apparait immediatement sur le site.

Cliquez ensuite sur **Creer l'enseignement**.

## 9. Modifier un enseignement

1. Dans la liste des enseignements, cliquez sur **Modifier** a droite de la
   ligne concernee.
2. Changez les informations souhaitees.
3. Cliquez sur **Enregistrer les modifications**.

Vous pouvez aussi publier ou depublier un enseignement directement depuis
la liste, sans passer par le formulaire, en cliquant sur **Publier** /
**Depublier**.

## 10. Supprimer un enseignement

Dans la liste des enseignements, cliquez sur **Supprimer**, puis confirmez
dans la fenetre qui s'affiche. Cette action est definitive : le fichier PDF
et l'image associes sont egalement supprimes.

## 11. Creer une categorie

1. Dans le menu de gauche, cliquez sur **Categories**.
2. Remplissez le formulaire **Nouvelle categorie** (nom, adresse web,
   description facultative).
3. Cliquez sur **Creer la categorie**.

Vous pouvez ensuite glisser-deposer une categorie dans la liste pour
changer l'ordre dans lequel elles apparaissent sur le site.

## 12. Consulter les statistiques

Le **Tableau de bord** (premiere page apres connexion) affiche :
- le nombre total d'enseignements, publies et en brouillon ;
- le nombre total de vues et de telechargements de PDF ;
- le top 5 des enseignements les plus consultes ;
- la repartition des enseignements par categorie ;
- l'activite recente (dernieres modifications).

## Gerer les utilisateurs (administrateurs uniquement)

Si vous avez le role **Administrateur**, un menu **Utilisateurs**
supplementaire est visible. Il permet de :
- creer un nouvel administrateur ou editeur ;
- modifier le nom, le role ou le mot de passe d'un utilisateur ;
- desactiver un compte (recommande plutot que de le supprimer si la
  personne a deja publie des enseignements) ;
- supprimer un utilisateur (sauf votre propre compte).

## Besoin d'aide ?

Contactez la personne technique en charge de la maintenance de la
plateforme pour toute question qui n'est pas couverte par ce guide.
